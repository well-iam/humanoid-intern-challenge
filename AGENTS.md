# humanoid-intern-challenge

## The challenge

Humanoid "Robot Learning Research" intern challenge. Full text: `docs/challenge.md`.

- Goal: use real data I recorded myself to drive a robotic manipulator in simulation (e.g. LIBERO), showing VLA and/or world-model skills.
- Hard rule: the data I collected must play a role in the approach.
- Deadline: Friday 16 October 2026, 23:59 BST. Submit as a public GitHub repo.
- Graded on: creativity, policy performance in simulation and/or world-model prediction quality, simplicity and clear presentation without AI slop.
- README must include: how to run, example outputs, design choices, what worked and what didn't.
